# Contract: Management Plane API

**Branch**: `001-s3-local-server` | **Date**: 2026-08-21

Separate from the S3 data plane (FR-018). Lives in the optional `tinio-api` crate behind the default-on `api` cargo feature; builds with `--no-default-features` omit this whole plane. Served by axum over the control channel by default: unix socket `tinio.sock` (mode 0600) in the state dir on Linux/macOS (configured via `[api.unix] path`); Windows named pipe `\\.\pipe\tinio-<sha1(canonicalize(root))[..16]>` (configured via `[api.pipe] path`; recorded in `state` as source of truth; also selectable via `--api pipe://<name>`; created with `FILE_FLAG_FIRST_PIPE_INSTANCE` so a second bind fails). The state dir is `<root>/.tinio/` normally and `~/.tinio/roots/<sha1(canonical root)16>/` in read-only mode (FR-023). A stale unix socket file is probed before bind and unlinked when no listener responds, so a crashed instance does not block a clean restart. Optionally also exposed over TCP HTTP/HTTPS via the `[api]` config section (`[api.http]` / `[api.https]` subsections — presence enables, omitted = off) or the `--api <URL>` CLI flag. Token auth: `X-Tinio-Token` header, value from `state` (CSPRNG-generated, ≥ 32 bytes). Binding the control channel enforces single-instance semantics; with the `api` feature compiled in, exactly one transport must be enabled after resolution — the local channel (`[api.unix]` on Linux/macOS or `[api.pipe]` on Windows), `[api.http]`, or `[api.https]` — three-choose-one (startup error otherwise). On graceful stop the server removes the socket file and `state`. Management-plane requests go to the operational log only — they are not written to the data-plane access log.

## Transport and auth matrix

| Transport | Enabled by | Token required |
|-----------|------------|----------------|
| Unix socket / named pipe (local channel) | always | `/status`, `/stop` only; `/metrics`, `/openapi.json` open (local-only channel) |
| TCP HTTP (`[api.http]` section present / `--api http://…`) | config or flag | ALL endpoints, including `/metrics` and `/openapi.json` |
| TCP HTTPS (`[api.https]` section present + cert/key, or `--api https://…`) | config or flag | ALL endpoints |

Rationale: over TCP the read endpoints leak operational data (object counts, traffic, API schema) to anything that can reach the host/port; Prometheus scrapers support bearer tokens for `/metrics`.

## Endpoints

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/status` | token | Server status (JSON) |
| POST | `/stop` | token | Graceful stop: cease accepting, drain in-flight ≤ 10 s, exit |
| GET | `/metrics` | none | Prometheus text exposition (3 metric layers) |
| GET | `/openapi.json` | none | OpenAPI spec generated by utoipa (`axum_extras`), incl. token security scheme |

## Responses

### GET /status

`200`:
```json
{
  "running": true,
  "pid": 1234,
  "host": "127.0.0.1",
  "port": 9000,
  "root": "E:\\data",
  "started_at": "2026-08-21T12:00:00Z",
  "version": "0.1.0"
}
```

### POST /stop

`202` `{"status": "draining"}` — server then drains and exits. If the drain timeout (10 s) expires, in-flight requests are cut and the process exits.

### Errors

- `401 {"error": "unauthorized"}` — missing/wrong token (status/stop).
- `404` — unknown path.
- `500 {"error": "..."}` — internal error.

### GET /metrics

`200` `Content-Type: text/plain; version=0.0.4; charset=utf-8`. Metric families: see data-model.md (HTTP / S3 operation / storage layers; full-scan gauges TTL-cached 30 s).

### GET /openapi.json

`200` `application/json` — utoipa-generated spec; documents the token security scheme and all four endpoints.

## CLI usage

`tinio status` / `tinio stop` are thin clients of this API (read `state` for channel + token, call status/stop).
