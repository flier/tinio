# S3 Owner & ACL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement real, enforced S3 ACLs with multi-user SigV4 authn — owner/ACL persistence in the shared table layer, a feature-gated `tinio-auth` crate, ACL operations and write-path ACL headers, and the full authorization matrix.

**Architecture:** ACL domain types and wire codecs land in tinio-core (like `Tags`); the shared redb rows are extended once (BUCKETS/OBJECT_META/UPLOADS) in tinio-store; authn/authz engine (S3Auth + S3Access + authorization matrix + canned-ACL expansion) lives in the new `crates/tinio-auth`, enabled in tinio-server via the `acl` Cargo feature and the `Capabilities.acl` runtime toggle. Enforcement happens at the single s3s `S3Access` seam before routing; per-key checks (DeleteObjects) live in the handler. On unix, an optional S3-principal → local-uid mapping (config-supplied via `local_uid`, injected into tinio-fs as plain `FsOptions` data — never from request data) chowns new object files (0600) and bucket/prefix dirs (0700) to the mapped owner/bucket-owner uid; the mapping is entirely config-driven and requires chown privilege (validated at startup) or startup fails.

**Tech Stack:** Rust, redb (shared table layer via tinio-store), s3s 0.15 (`S3Auth`/`S3Access`), tokio, thiserror, garde (config), hmac+sha2 (e2e SigV4 test signer).

**Spec:** `docs/superpowers/specs/2026-09-05-s3-acl-owner-design.md` — the plan argues from the spec; executors read both.

```rust
const CANONICAL_ID_LEN: usize = 64;

pub struct OwnerId(String);
impl OwnerId {
    pub fn new(s: impl Into<String>) -> Result<Self, AclError> {
        let s = s.into();
        if s.len() == CANONICAL_ID_LEN && s.bytes().all(|b| b.is_ascii_hexdigit() && !b.is_ascii_uppercase()) {
            Ok(Self(s))
        } else {
            Err(AclError::InvalidOwnerId(s))
        }
    }
    pub fn as_str(&self) -> &str { &self.0 }
}
// impls: Debug, Clone, PartialEq, Eq, Hash
// PartialEq<str> helper: `impl PartialEq<str> for OwnerId` and `PartialEq<&str>` so access-columns compare (P == O) by `owner == p.as_ref()` — otherwise resolve to strings at call sites.

pub enum Permission { FullControl, Read, ReadAcp, Write, WriteAcp }
impl Permission {
    pub fn as_wire(&self) -> &'static str {
        match self { Permission::FullControl => "FULL_CONTROL", Permission::Read => "READ",
                    Permission::ReadAcp => "READ_ACP", Permission::Write => "WRITE",
                    Permission::WriteAcp => "WRITE_ACP" }
    }
    pub fn from_wire(s: &str) -> Result<Self, AclError> {
        Ok(match s { "FULL_CONTROL" => Permission::FullControl, "READ" => Permission::Read,
                     "READ_ACP" => Permission::ReadAcp, "WRITE" => Permission::Write,
                     "WRITE_ACP" => Permission::WriteAcp, _ => return Err(AclError::InvalidPermission(s.into())) })
    }
}

pub const GROUP_ALL_USERS: &str = "http://acs.amazonaws.com/groups/global/AllUsers";
pub const GROUP_AUTHENTICATED_USERS: &str = "http://acs.amazonaws.com/groups/global/AuthenticatedUsers";
pub const GROUP_LOG_DELIVERY: &str = "http://acs.amazonaws.com/groups/s3/LogDelivery";
// No EC2 group constant: AWS documents only the three URIs above (grilling Q5).

pub struct GroupUri(pub String);
impl GroupUri {
    pub fn is_valid(&self) -> bool {
        matches!(self.0.as_str(), GROUP_ALL_USERS | GROUP_AUTHENTICATED_USERS | GROUP_LOG_DELIVERY)
    }
}

pub enum Grantee { Canonical(OwnerId), Group(GroupUri) }

pub struct Grant { pub grantee: Grantee, pub permission: Permission }

pub type AclGrants = Vec<Grant>;
pub const ACL_GRANTS_MAX: usize = 100;

pub struct Acl { pub owner: Option<OwnerId>, pub grants: AclGrants }

impl Acl {
    pub fn default_private(owner: Option<OwnerId>) -> Self {
        let mut grants = Vec::new();
        if let Some(o) = &owner {
            grants.push(Grant { grantee: Grantee::Canonical(o.clone()), permission: Permission::FullControl });
        }
        Self { owner, grants }
    }

    fn grantee_wire(g: &Grantee) -> Option<String> {
        Some(match g {
            Grantee::Canonical(id) => format!("id={}", id.as_str()),
            Grantee::Group(uri) if uri.is_valid() => format!("uri={}", percent::encode(&uri.0)),
            Grantee::Group(_) => return None,
        })
    }

    pub fn to_grants_wire(&self) -> String {
        let entries: Vec<String> = self.grants.iter()
            .filter_map(|g| Some(format!("{},{}", Self::grantee_wire(&g.grantee)?, g.permission.as_wire())))
            .collect();
        let mut entries = entries;
        entries.sort();
        entries.dedup();
        entries.join("&")
    }

    pub fn from_grants_wire(s: &str) -> Self {
        Self::parse_grants_wire(s).unwrap_or_else(|_| Self::default_private(None))
    }

    fn parse_grants_wire(s: &str) -> Result<Self, AclError> {
        let mut grants = Vec::new();
        for part in s.split('&').filter(|p| !p.is_empty()) {
            let (gee, perm) = part.split_once(',').ok_or(AclError::InvalidPermission(part.into()))?;
            let grantee = if let Some(id) = gee.strip_prefix("id=") {
                Grantee::Canonical(OwnerId::new(id)?)
            } else if let Some(raw_uri) = gee.strip_prefix("uri=") {
                let uri = percent::decode(raw_uri).map_err(|_| AclError::InvalidGroupUri(raw_uri.into()))?;
                let uri = GroupUri(uri);
                if !uri.is_valid() { return Err(AclError::InvalidGroupUri(uri.0)); }
                Grantee::Group(uri)
            } else { return Err(AclError::InvalidGroupUri(gee.into())); };
            grants.push(Grant { grantee, permission: Permission::from_wire(perm)? });
        }
        if grants.len() > ACL_GRANTS_MAX { return Err(AclError::GrantsOverflow); }
        // canonical: sort + dedupe identical (grantee, permission)
        let mut keyed: Vec<(String, Grant)> = grants.into_iter().filter_map(|g| {
            Some((format!("{},{}", Self::grantee_wire(&g.grantee)?, g.permission.as_wire()), g))
        }).collect();
        keyed.sort_by(|a, b| a.0.cmp(&b.0));
        keyed.dedup_by(|a, b| a.0 == b.0);
        Ok(Self { owner: None, grants: keyed.into_iter().map(|(_, g)| g).collect() })
    }
}
```
